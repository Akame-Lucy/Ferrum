# Code of Conduct

## Our standard

Ferrum adopts the [Contributor Covenant v2.1][covenant] as its code of conduct.
The full text is at the link; the short version is that everyone participating
in this project - issues, pull requests, discussions, reviews - is expected to
behave in a way that keeps this a place people want to contribute to.

Concretely, that means:

- Assume good faith. A confusing PR is usually a communication gap, not
  incompetence.
- Critique the code, not the person. "This lets a path escape its root" is
  review; "did you even think about this" is not.
- Accept that maintainers say no. A rejected feature is not a personal verdict,
  and a project that accepts everything becomes a project nobody can maintain.
- No harassment, personal attacks, demeaning comments, or unwelcome attention,
  in public or in private, in any form.

## Scope

This applies in every project space - the repository, its issues and pull
requests, discussions, and any place where someone is representing Ferrum.

## Reporting

If you experience or witness behaviour that breaks this, report it privately to
the maintainers. Do not open a public issue about it.

## Enforcement

Maintainers may remove, edit, or reject comments, commits, code, issues, and
other contributions that do not meet this standard, and will explain why when
they do. Sustained or serious violations can result in a temporary or permanent
ban from project spaces.

The Contributor Covenant's [enforcement guidelines][guidelines] describe the
escalation ladder - correction, warning, temporary ban, permanent ban - and are
the reference used here.
